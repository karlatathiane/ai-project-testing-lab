# AI Project Testing Lab

## Overview

This repository contains documentation and sample requirements for four fictional software projects inspired by animated movies.

The repository is intended to support the evaluation of AI-powered project management and software testing platforms, including their ability to generate:

* Product backlogs
* Epics and user stories
* Acceptance criteria
* Functional and non-functional requirements
* Test cases and test scenarios
* Sprint plans
* Task breakdowns
* Requirement traceability

## Projects

### 1. Monster Energy Management

**Organization:** Monstros SA
**Prefix:** MEM
**Methodology:** Scrum

A web application for managing energy production, employee performance, dimensional doors, and operational incidents in a monster-powered energy factory.

**Main features:**

* Employee management
* Energy production monitoring
* Dimensional door management
* Incident tracking
* Operational dashboards

### 2. El Dorado Exploration System

**Organization:** Eldorado
**Prefix:** EES
**Methodology:** Kanban

A web application for managing archaeological expeditions, cataloging artifacts, tracking exploration resources, and recording discoveries.

**Main features:**

* Expedition management
* Explorer registration
* Artifact catalog
* Resource management
* Discovery reports

### 3. Treasure Planet Navigation System

**Organization:** Treasure Planet
**Prefix:** TPNS
**Methodology:** Scrum

A web application for planning space expeditions, managing spacecraft and crews, tracking missions, and recording discoveries across unexplored planets.

**Main features:**

* Spacecraft management
* Interplanetary route planning
* Crew and resource management
* Mission monitoring
* Discovery tracking
* Critical incident alerts

### 4. Atlantis Research & Preservation

**Organization:** Atlantis
**Prefix:** ARP
**Methodology:** Scrum

A web application for managing underwater research expeditions, cataloging artifacts, monitoring environmental conditions, and preserving an ancient civilization's heritage.

**Main features:**

* Underwater expedition management
* Artifact cataloging
* Environmental monitoring
* Equipment management
* Research team management
* Safety alerts

## Evaluation Goals

The projects can be used to evaluate whether an AI-powered platform can:

1. Identify functional and non-functional requirements.
2. Generate clear and testable user stories.
3. Create acceptance criteria aligned with requirements.
4. Generate positive, negative, boundary, and permission-based test cases.
5. Identify ambiguities and missing business rules.
6. Organize work into a coherent backlog.
7. Propose sprint plans that respect dependencies and priorities.
8. Maintain traceability between requirements, user stories, and test cases.

## Notes

All projects are fictional and intended for software development and testing exercises.

The project descriptions provide initial context. Additional requirements and business rules should be documented separately as each project evolves.
